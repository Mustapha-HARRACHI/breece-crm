# Project conventions

- Use the MERN stack: MongoDB, Express, React, and Node.js.
- Use JavaScript, not TypeScript, unless explicitly requested.
- Expose server functionality through a REST API under `/api`.
- Prefer a simple modular architecture with minimal dependencies and abstractions.
- Follow security-first development: validate inputs, keep secrets in environment variables, and avoid exposing sensitive data.
- Keep changes focused and report work concisely.
